# 区间 DP：第一次做会改变邻居，试着改枚举最后一次

> [算法路线](00-guide.md) · 独立原创

**「先干掉谁」可能让左右子问题互相影响；选最后消失的元素能把边界固定下来。**

## 边界只作为邻居，不在子问题中被移除

戳气球类问题中，给数组两端补 `1`；用 `dp[lo][hi]` 表示移除开区间 `(lo,hi)` 中所有气球的最大得分。若 `last` 是最后被戳的气球，那么最后一次的两个邻居正好是 `lo`、`hi`。其余步骤可分为 `dp[lo][last] + dp[last][hi]`，最后再加三个边界值相乘的收益。相邻边界中没有元素，得分 `0`。

按开区间长度从小到大填表，就能保证转移指向已解区间。对 `[3,1,5,8]` 最大得分 `167`；对子区间先算最佳，不要假设局部贪心顺序可拼成全局最佳。时间 `O(n³)`、额外空间 `O(n²)`。

实现：[maxBalloonScore](../code/algorithm-node/src/dynamic.ts)。

练习：手算两个气球 `[2,5]`，分别让 `2` 或 `5` 最后戳，答案是多少？
