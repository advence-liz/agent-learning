# 股票 DP：次数与手续费

> [算法路线](00-guide.md) · 独立原创

**交易上限决定状态里要不要记次数，手续费决定每次卖出要减掉多少。** 两者约束的是不同东西：一个限制能卖几次，另一个允许多卖但让每次卖出变贵。

- [拆开计数与收费](#method)：用昨日的持仓和现金推今日。
- [逐日对照](#worked-example)：同一组价格计算三个版本。
- [列举合法操作](#verify)：检查最后一天和重复扣费。

## 交易在卖出时计数，收费在同一步扣除 { #method }

前提：每天给一个非负价格 `p`，一天至多做一次操作，至多持有一股，不可做空；买入再卖出算一笔完整交易，无冷冻期。开始没有持仓，结束必须空仓，允许不交易。手续费 `f ≥ 0`，每笔只收一次，这里放在卖出时扣。

| 昨日状态 | 今日选择 | 今日状态 | 现金变化 |
| --- | --- | --- | --- |
| `cash[t]`：已卖 `t` 次、空仓 | 等待或买入 | `cash[t]` 或 `hold[t]` | `0` 或 `-p` |
| `hold[t]`：已卖 `t` 次、持仓 | 等待或卖出 | `hold[t]` 或 `cash[t+1]` | `0` 或 `p-f` |

这里的值是对应状态能留下的最大现金，不给持仓按市价估值；`t` 是**恰好**完成的次数。初始仅 `cash[0]=0`，其他状态为 `-∞`。每个新状态从所有合法昨日来源取最大值：`cash'[t]=max(cash[t],hold[t-1]+p-f)`，其中 `t=0` 无卖出来源；`hold'[t]=max(hold[t],cash[t]-p)`。只保留 `0≤t≤k` 的空仓与 `0≤t<k` 的持仓，缺失状态视为不可达。全部转移只读昨天的数组，最后取 `max(cash[0..k])`。`k=0` 或空价格序列直接得 `0`；有限次数版用双缓冲，时间 `O(nk)`、额外空间 `O(k)`（`k≥1` 时）。

**只有手续费、次数不限**时，过去卖了几次不影响未来，直接把 `t` 删掉：`cash'=max(cash,hold+p-f)`、`hold'=max(hold,cash-p)`。初值仍是一空仓可达、一持仓不可达，最后读 `cash`，时间 `O(n)`、额外空间 `O(1)`。如果两条限制同时存在，就保留次数维并扣手续费。

## 次数上限和手续费会给出不同的最优计划 { #worked-example }

价格依次为 `2,5,1,6`。表中有限次数两列不收手续费，第三列不限次数、卖出扣 `2`：

| 今日价格 | 恰好卖 1 次的现金 | 恰好卖 2 次的现金 | 手续费版 `(空仓, 持仓)` |
| --- | --- | --- | --- |
| 2 | 不可达 | 不可达 | `(0,-2)` |
| 5 | `3` | 不可达 | `(1,-2)` |
| 1 | `3` | 不可达 | `(1,0)` |
| 6 | `5` | `8` | `(4,0)` |

例如手续费版在价格 `1` 时可以买入，现金变为前一天空仓的 `1-1=0`；最后卖出得到 `0+6-2=4`。不收费、至多一笔只能拿 `6-1=5`；至多两笔则可拿 `(5-2)+(6-1)=8`。如果既限一笔又收 `2`，最优变成 `3`。

## 用小规模操作枚举验证边界和收费反例 { #verify }

- **边界练习**：对单日价格 `[7]` 检查答案为 `0`，而「恰卖一次」仍不可达；对 `[7,6,5]` 检查「至多」的答案也是 `0`，而不是被迫亏损。
- **反例**：价格 `[1,4,6]`、手续费 `2`，把相邻上涨段分别减手续费只能得 `max(0,3-2)+max(0,2-2)=1`。第一天买、第三天卖只付一次，得 `3`。
