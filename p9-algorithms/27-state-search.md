# 状态空间搜索：从格子、单词到双向 BFS

> [算法路线](00-guide.md) · 独立原创

**图不一定显式存在：只要能枚举某个状态的一步转移，就能做搜索。** `visited` 必须对应完整状态，不能只存看起来像位置的字段。

## 行列相同，手里有没有钥匙却可能改变未来

迷宫中门依赖已拾取钥匙，应该标记 `(row,col,keyMask)`；只记 `(row,col)` 可能把拿钥匙后的回访剪掉。邻接是合法的一步移动，要求最少步数就 BFS，入队时去重。格子 `R×C`、`k` 把钥匙时，状态上界 `RC·2^k`；不能只按格子数估时空成本。

若起点和终点都明确，且反向转移能正确生成（无向图可用同样邻居），可用双向 BFS，从两边各按层扩张，通常优先扩较小前沿。在一般有向图上从终点沿原图正向扩张，找到的交集不能拼成有效路径。也可以多源 BFS：将所有起点以距离 `0` 同时入队，求每点到最近源的最少步数。
