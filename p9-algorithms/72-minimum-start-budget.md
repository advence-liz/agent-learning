# 最小初始资源：逆推每个格子进入前最低需要多少

> [算法路线](00-guide.md) · 独立原创

**最大化最终余额和确保途中从不破产不是同一个目标。** 逆向 DP 把历史条件改写成未来需要的下界。

网格每步向右或向下，经过每一格即时加上格值，任何时候余额都要至少 `1`。令 `need[r][c]` 为进入该格前最小余额。选后继中要求较小的 `q`，再解 `balance + value >= q` 以及进入前余额至少 `1`，得到 `max(1,q−value)`。终点后要求为 `1`；没有合法的后继视为无穷，不可达要单独回报。无障碍矩形查询时间、空间 `O(RC)`，只取初值则一行即可 `O(C)`。

`[[-4,6],[-1,-2]]` 中走右再下需要至少 `5`，走下再右需要 `8`，所以答案 `5`。仅看总和会以为右路总和 `0`、初始 `1` 就够，但第一格已破产。

练习：把起点变成 `+5`，其他格不变，答案是多少？

<details>
<summary>提示</summary>

至少 `1`，而且 `1` 足以走右路。转移中的 `max(1,…)` 不能因为格值为正就省掉。

</details>
