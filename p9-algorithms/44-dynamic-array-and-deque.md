# 动态数组和环形队列：把移动成本留给扩容

> [算法路线](00-guide.md) · 独立原创

**频繁首删不要靠每次搬数组；环形队列移动的是逻辑队头。** `head` 与元素个数共同决定哪些槽有效。

## 用 `size` 区分空与满

容量 `4` 时，`head=3,size=2` 的有效下标依次是 `3,0`；下次入队写 `(head+size)%capacity=1`。出队读 `head`，清掉旧引用，然后 `head=(head+1)%capacity,size--`。空与满时，若只看首尾下标相等会分不清；可以记录 `size`，或者故意浪费一个槽。

扩容时按**逻辑**次序复制到新缓冲区，并设 `head=0`。几何扩容让每次入队摊销 `O(1)`，最坏仍是一次完整搬运；固定容量则可选择拒绝新值，覆盖最旧值是另一种契约。使用 `size` 还能避免把合法的 `undefined` 元素误判为队列为空。
