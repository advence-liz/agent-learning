# 二分图染色与奇环

> [算法路线](00-guide.md) · 独立原创

要把无向图分成两个组，使每条边跨组，**从每个连通分量的任一点出发，给邻点染相反的色。** 如果遇到一条两端同色的边，不仅能判失败，还能沿搜索树找出一条奇环作为证据。

- [传播颜色](#method)：没染过的连通分量都要另起一轮。
- [导出证据](#worked-example)：保留父指针，就能给出违反二分条件的环。
- [检查边界](#verify)：不连通、自环、平行边分别验。

## 广度优先搜索把跨组约束传给每个邻点 { #method }

前提：`V` 个点、`E` 条无向边，点可以孤立，允许平行边，也允许输入自环。每点颜色初始为未染，`parent` 存搜索树父节点。按任意顺序检查每个点；遇未染点，把它染 `0`、设父节点为空，再开启一轮 BFS：

```text
每次出队 u，扫描每条相邻边 u—v：
    若 v 未染：color[v] = 1-color[u]，parent[v] = u，把 v 入队
    否则若 color[v] = color[u]：停止，记录冲突边 (u,v)
全部分量扫描完且无冲突：按 0/1 颜色输出二分
```

染色发生在入队时，不等到出队，避免一个点被多个父节点重复认领。所有边都已检查且跨色就构成合法二分。时间 `O(V+E)`，邻接表以外的颜色、父指针和队列共 `O(V)` 空间；构造一个奇环另需 `O(V)` 时间和空间，不改变总复杂度。

## 同色边和两条树枝拼成奇环 { #worked-example }

例子有五条边 `A—B、A—C、B—D、C—E、D—E`。从 `A` 开始，先扫描 `B` 再扫描 `C`：

| 从 A 的深度 | 新染点及颜色 | 树父节点 |
| --- | --- | --- |
| 0 | `A:0` | 无 |
| 1 | `B:1、C:1` | 都是 `A` |
| 2 | `D:0、E:0` | `D←B，E←C` |

扫描 `D—E` 时两端已同为 `0`。通用重建做法：沿 `u` 的父链把祖先标好，再沿 `v` 的父链找到第一个已经标过的点 `a`；把 `u` 到 `a` 的树路径接上反向的 `v` 到 `a` 的树路径，再用冲突边返回 `u`。例子得到 `D—B—A—C—E—D`。两条树枝除 `a` 外没有交点，且颜色沿树边交替，同色端点之间的树路必为偶数长度；加一条冲突边就是奇数。奇环不可能交替染两色，因此任何重新染色都没用。若冲突边是自环，直接返回长度 `1` 的环。

## 用小图同时核验颜色和证据 { #verify }

- **只跑一次的反例**：图同时有边 `A—B` 和三角形 `C—D—E—C`。从 `A` 跑一次只能看到跨色边，但全图不是二分图。
- **边界练习**：两点之间放两条平行边，仍可二分；再给其中一点加自环，必须返回奇环。只有孤立点的图应通过，孤点分到哪一组都行。
