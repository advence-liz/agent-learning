# 前缀频次：有负数的子数组和为什么改成查表

> [算法路线](00-guide.md) · 独立原创

**连续子数组和等于目标时，记录此前前缀出现了几次；不需要猜左右指针该往哪挪。** 数组含负数时，扩张不保证更大。

## 把区间等式改写成此前前缀的查询

处理到位置 `j`，令 `s` 是 `[0,j+1)` 的和。每个先前边界 `i` 若满足 `prefix[i]=s−target`，就对应一个合法非空区间；把这份频次加进答案，然后才把当前 `s` 的频次加一。先放 `freq[0]=1`，因为从最左边开始的区间也应被计入。`[1,-1,1]` 目标 `1` 时，累计贡献是 `1,0,2`，总计 `3`。

```ts
const seen = new Map([[0, 1]]);
let sum = 0;
let count = 0;
for (const x of values) {
  sum += x;
  count += seen.get(sum - target) ?? 0;
  seen.set(sum, (seen.get(sum) ?? 0) + 1);
}
```

[完整函数及边界](../code/algorithm-node/src/indexing.ts)按哈希平均常数访问估算，时间 `O(n)`、空间 `O(n)`；要求累加与计数保持精确。若题目改为求最长长度，应改记最早边界，而不是频次或最近下标。
