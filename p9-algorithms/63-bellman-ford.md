# Bellman–Ford 与负环

> [算法路线](00-guide.md) · 独立原创

有负边的有向图里，**先反复用整张边表改善单源距离，再用额外一次扫描找出被负环影响的区域。** 负环只有从源点能到、且它能再走到查询点时，才会让该查询的最短路无下界。

- [松弛距离](#method)：边顺序可让信息提前传播，但不会推迟保证。
- [传播负环影响](#worked-example)：区分有限距离、不可达和无下界。
- [验算边表](#verify)：逐轮对照距离，再局部接入负环。

## 每轮扫描至少覆盖多走一条边的可能 { #method }

给定 `V≥1` 个点、`E` 条有向边，边权可正可负，起点 `s` 固定。距离按允许重复点和边的走法定义。`dist[v]` 存当前已找到的一条最短走法的代价，初始 `dist[s]=0`、其他为 `+∞`。一次松弛：只在 `dist[u]` 有限时，若 `dist[u]+w < dist[v]`，就用该值更新 `v`。不对不可达哨兵做算术。

重复扫描整张边表至多 `V-1` 轮，每一轮可就地更新；整轮无更新可以提前结束。归纳可知，扫完第 `k` 轮，`dist[v]` 不大于任一至多走 `k` 条边的 `s→v` 走法代价：第 `k` 条边被扫到时，其起点至少已经拥有前 `k-1` 轮的结果。就地更新也可能提前纳入更长的走法，但每个有限值都对应一条真实走法。若 `v` 不受负环影响，去掉走法上的环不会使代价增加，最短值可由至多 `V-1` 条边的一条简单路实现。

## 额外一轮找到的是影响区域的种子 { #worked-example }

```text
用 V-1 轮（可提前终止）完成 dist
固定 dist 不变，再扫描每条边 (u,v,w)：
    若 dist[u] 有限且 dist[u] + w < dist[v]，将 v 作为种子
沿原图的有向边，从所有种子一起做可达性搜索
    被搜到：-∞（代价可任意小）
    未搜到且 dist[v] = +∞：不可达
    其余：返回有限 dist[v]
```

若一个可达负环上的每条边都不能松弛，把这些不等式绕环相加会得到环权重非负，矛盾；所以环上至少有一个种子。反过来，若某个种子不受任何可达负环影响，那么它的有限最短路在前 `V-1` 轮已找到，不应还能被改善。标记必须沿**原方向**向后继传播，不能把负环上游也一起标掉。

边表松弛最坏耗时 `O(VE)`，加初始化、构建邻接表及传播共 `O(VE+V+E)`；包括边表和邻接表在内空间 `O(V+E)`，若它们已提供则额外 `O(V)`。

## 从四个点的边表手算三轮 { #verify }

源点 `S`。按 `B→C(2)`、`A→B(-4)`、`S→A(3)`、`S→C(9)` 的顺序扫描，`S` 始终为 `0`：

| 扫描后 | A | B | C |
| --- | --- | --- | --- |
| 初始化 | `∞` | `∞` | `∞` |
| 第 1 轮 | `3` | `∞` | `9` |
| 第 2 轮 | `3` | `-1` | `9` |
| 第 3 轮 | `3` | `-1` | `1` |

`B→C` 在第 2 轮先于 `A→B` 扫到，因此要等第 3 轮才能用 `-1+2=1` 改善 `C`。另在边表末尾加入 `C→B(-3)`，此时环 `B→C→B` 总权为 `-1`。三轮后 `B=-2、C=1`，额外扫描发现 `B→C` 还能把 `C` 改成 `0`；从种子 `C` 能回到 `B`，故两点均为 `-∞`，而 `A` 仍为 `3`。

- **反例**：只有 `S→T(4)、U→V(-2)、V→U(1)` 时，图上虽然有负环，但 `U、V` 不可达，`T` 的答案仍为 `4`。增加 `S→U(10)` 后，`U、V` 变成 `-∞`，`T` 仍是 `4`；再加 `V→T(0)`，`T` 才变成 `-∞`。

<details>
<summary>核验提示</summary>

对小图枚举简单路径和简单有向环（含自环）。若能从源到某个负环、再从负环到查询点，预期 `-∞`；否则用最短简单路径或不可达作答案。打乱边表再算，最终三类结果不应改变。

</details>
