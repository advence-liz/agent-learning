# 分治：先确认左右独立，再设计跨边界合并

> [算法路线](00-guide.md) · 独立原创

**分治的难点通常不是切半，而是算清跨边界项；只切不合并得不到答案。**

## 对跨区间项单独写公式

最大连续子数组可让每段返回四个值：总和、最佳非空前缀、最佳非空后缀、最佳非空子区间。合并时 `best=max(left.best,right.best,left.suffix+right.prefix)`；三种候选覆盖只在左、只在右、跨界。前缀要么停左，要么用完整左段接右侧最佳前缀。后缀对称。

单个负数的四个值都应是它自己，不能用 `0` 敷衍，否则全负输入会错误选空区间。合并 `O(1)`，有 `O(n)` 个节点，总时间 `O(n)`，栈 `O(log n)`。只求一次最大和可用更简单的线性 DP；同一结合公式也能打包进线段树，支持在线更新。

练习：手算 `[-3,4]` 与 `[2,-5]` 的汇总，再合并。
