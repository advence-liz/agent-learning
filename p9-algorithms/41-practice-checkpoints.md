# 综合练习：先交付可验证的答案，再追求题数

> [算法路线](00-guide.md) · 独立原创

**一题过关要同时能解释条件、证明关键一步、跑边界测试。** 下面是按知识依赖排列的阶段作业，不是仅打勾的题单。

| 关卡 | 任务 | 可自检的输入 |
|---|---|---|
| 查表和范围 | 多次批量区间加后求矩形内命中数；把不同维度分别建模 | `n=5`、区间更新相接且含空区间，朴素法对拍 |
| 指针和决策 | 求满足阈值的最小容量 | `[3,2,2,4]`、两天，`5` 不够、`6` 够 |
| 容器和树 | 订单缓存加入 LRU；BST 校验不许漏祖先边界 | 读命中后淘汰另一项；`5→8→左4` 非法 |
| 图 | 非负权图查询最短路并恢复路径 | `a→b(8)` 和 `a→c(1)→b(0)`，走后者 |
| DP | 0/1 背包加选项还原，和枚举对拍 | 单件重 `2` 价 `4`、容量 `4` 结果只能 `4` |
| 数学 | 从日志流等概率保留一条，逐项证明 | 第 `i` 项后每个已见元素概率 `1/i` |

先写直接但较慢的版本做小输入判定，再写优化；记录最小反例并说清为什么原法崩溃。进阶开放题：给[任务规划器](07-task-planner.md)输出精确环成员、阻塞后继与最大并行批次数的区别；不要把任意拓扑顺序当成最短工期。

<details>
<summary>验收提示</summary>

同一关卡至少覆盖空输入、重复或相接、不可达或不可行中的适用项。规划器上的环模块可以用 SCC；最大并行批次需另定义每个任务耗时与资源，不是加一个优先级字段就能得出。

</details>
