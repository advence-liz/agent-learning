# 排序与堆：只要 Top K，就不用给所有元素排序

> [算法路线](00-guide.md) · 独立原创
>
> **一句话：**归并排序让整个数组有序；堆只保证下一位是谁。只要最大的 `k` 项时，用一个小顶堆守住第 `k` 名，比给所有元素排名更贴近需求。

## 同一份输入，先决定要完整榜单还是只要前几名

```bash
node code/algorithm-node/examples/06-ordering.ts
```

```text
sorted: [1,2,4,9,9]
top 3: [9,9,4]
```

### 归并利用两段已经有序，只比较各自队首

把范围切成 `[lo,mid)` 和 `[mid,hi)`，递归排好；合并时，下一项最小值只能在两个队首之一。取较小值写进临时数组，并只推进被取值的一侧，最后复制回原区间。等值时取左侧；这个规则在给记录排序时可保住等值项的原始相对顺序，即稳定性（stability）。直接对整个输入只分配一次共享临时数组。每一层合并共处理 `n` 项，层数为 `O(log n)`，所以时间 `O(n log n)`，额外空间 `O(n)`，包含 `O(log n)` 的调用栈。

### 堆根只告诉你下一位，不意味着数组整体已排序

二叉堆（binary heap）用数组表示完全二叉树。下标 `i` 的左、右孩子分别是 `2i+1`、`2i+2`；小顶堆只要求父节点不大于子节点。入堆先追加到底部再上浮；出堆取走根，把尾项放到根，再沿较小孩子下沉。`peek` 是 `O(1)`，一次 `push` 或 `pop` 是 `O(log h)`，其中 `h` 在这里表示堆中的元素数。

流式求最大 `k` 项：堆没满就加入；满了只比较新值与堆顶。堆顶是当前前 `k` 项里最小的，是唯一需要被挑战的门槛。用 `[4,9,1,9,2]`、`k=3` 走一遍：

| 处理完 | 堆里保留的值（这里按升序展示） | 满堆后的门槛 |
|---|---|---|
| `4,9,1` | `1,4,9` | `1` |
| 再来 `9` | `4,9,9` | `4` |
| 再来 `2` | `4,9,9` | `4` |

`largestK` 最后把堆按升序弹空，再反转得到降序，不会吞掉重复值。设 `m=min(k,n)`，最坏时间 `O(n log(m+1))`（`k=0` 直接返回），空间 `O(m)`。当 `k` 接近 `n`，优势就不明显；全局顺序或稳定性才是需求时，用完整排序更直接。见[归并与堆源码](../code/algorithm-node/src/ordering.ts)。

## 练习：用已知正确的排序做对拍

1. 用同一批输入比较 `largestK(values, k)` 和「复制、降序排序、截前 `k`」的基线。

<details>
<summary>提示</summary>

至少覆盖 `k=0`、`k=1`、`k>n`、重复值和负数。数值排序要传比较函数 `(a,b) => b-a`，不要用 JS 默认的字符串顺序。

</details>

2. 数据不断到来，要持续展示前 `k` 名。能不能每来一项就把堆弹空来展示？

<details>
<summary>提示</summary>

弹空会毁掉下一轮需要的保留状态。可以为展示单独做快照并排序；随后比较更新成本和输出完整榜单的成本，不用把两者绑成同一个操作。

</details>
