# 哈希与 LRU：按键定位和按顺序淘汰是两种操作

> [算法路线](00-guide.md) · 独立原创

**LRU 要同时快速找到键和淘汰最久未访问项。** 传统实现让哈希表负责定位，双向链表负责维护最近次序。

## 命中也会改变顺序

容量 `2`：写 `A`、写 `B`、读 `A`、写 `C`，被淘汰的是 `B`，不是最早写的 `A`。双向链表用两个哨兵，命中后摘下同一节点并移至最近端；容量超出时从另一端删节点，还要删除 `Map` 中对应键。单链表只拿到节点时找不到前驱，会把摘除操作变成线性扫描。

| 操作 | 先做什么 | 别漏什么 |
|---|---|---|
| 读取 | 查键并移动节点 | 未命中不可乱改次序 |
| 覆盖 | 改现有节点 | 不应生成第二个同键节点 |
| 淘汰 | 删除最旧节点 | 哈希索引同步删除 |

基于哈希平均常数访问可达均摊 `O(1)`，空间 `O(capacity)`。JS 也可利用 `Map` 插入顺序，但更新旧键不会自行改变顺序，必须先删后插。
