# 树与状态机 DP：有限状态承载未来需要的历史

> [算法路线](00-guide.md) · 独立原创

**当一种历史会改变下一步是否合法，把它压成状态而非重放所有选择。** 树上的「选父」和股票的「是否持有」都属于这个套路。

## 状态只记录影响未来的那一位

树上选权重最大的不相邻节点：`take(node)=value+skip(left)+skip(right)`；`skip(node)=max(take(left),skip(left))+max(take(right),skip(right))`。空树两值 `0`，从孩子向父汇总即可。时间 `O(n)`，递归深度 `O(h)`。可选空集合时，全负权应返回 `0`。

股票有冷却时，可以分别保存上一天末「持有」「刚卖出」「空仓可买」最大收益；买只能从上一日可买态进入，不能在刚卖出的下一天立即买。用同一份旧快照转移，别覆盖了一个当前状态又让别的状态读到它。长度 `n` 的价格序列、常数状态数，时间 `O(n)`、额外空间 `O(1)`；若限制交易次数，应再加交易次数维度。

练习：树根权重 `4`，两个叶分别 `3`、`3`，最优值？股票 `[1,2,3,0,2]` 有一天冷却时呢？
