# 最长回文子序列

> [算法路线](00-guide.md) · 独立原创

要在保留字符顺序、允许跳过字符的前提下找最长回文，**把状态定义在闭区间 `[l,r]`，让较短的区间先算完。** 两端相同就收下这一对，两端不同就比较丢左和丢右。

- [推导转移](#method)：说明为什么不必额外比较「跳过」。
- [按长度填表](#worked-example)：算出长度，也找回一条具体答案。
- [设计验证](#verify)：用短串枚举查错。

## 端点相等时可以把最优解改成使用两端 { #method }

前提：输入是一列可判等的符号，长度为 `n`；子序列只要求下标严格递增。令 `dp[l][r]` 是 `s[l..r]` 中最长回文子序列的长度。空区间长 `0`，单字符长 `1`。

| 长度至少为 2 的区间 | 转移 |
| --- | --- |
| `s[l] != s[r]` | `max(dp[l+1][r], dp[l][r-1])` |
| `s[l] == s[r]` | `2 + dp[l+1][r-1]` |

若两端不同，一个回文不可能同时用它们，否则首尾不等；任何合法解至少漏一端。若两端相同，收下它们必能围住一个内层最优解。反过来，取任意最优回文：它若两端都没用，就还能加长，不可能最优；若只用了一个端点且长度至少为 `2`，就把与该端点配对的字符挪到另一端，长度不变。长度 `1` 也不会最优，因为这一对本身就长 `2`。因此存在一个同时用两端的最优解。

## 短区间填完以后才能重建长区间的答案 { #worked-example }

先填 `len = 1`，再依次填到 `n`。对每个起点 `l`，令 `r = l + len - 1`。相邻相等字符直接用空区间的 `0`，不访问负下标。空输入直接返回 `0`；否则读 `dp[0][n-1]`。时间和空间均为 `O(n²)`。

以 `cabacb` 为例，每一行列出给定区间长度下、起点从左到右的状态值：

| 区间长度 | 各起点对应的 `dp` |
| --- | --- |
| 1 | `1, 1, 1, 1, 1, 1` |
| 2 | `1, 1, 1, 1, 1` |
| 3 | `1, 3, 1, 1` |
| 4 | `3, 3, 3` |
| 5 | `5, 3` |
| 6 | `5` |

重建时，首尾 `c != b`，丢右端可以保留长度 `5`，丢左端只能保留 `3`。进入 `cabac` 后收下 `c…c`，再收下 `a…a`，最后留下 `b`。通用重建规则：两端相同就分别记入结果的两侧并向内缩；不等就缩向较大值的子区间，平局任取；最后把左侧字符、中心字符、反转后的右侧字符拼接。重建需 `O(n)` 时间及 `O(n)` 输出空间。

## 用非连续回文和空区间测试 { #verify }

- **边界练习**：手填空串、`q`、`qq`、`qr`，期待 `0、1、2、1`。再构造一个长度 `4` 的字符串，使最优答案不唯一，并检查重建中两种平局处理都合法，例如 `abca` 的 `aba` 和 `aca`。
- **反例**：`abca` 的最长回文子序列长 `3`，但最长连续回文子串只长 `1`。若状态用的是「整个区间是否回文」，就不能直接回答本题。
