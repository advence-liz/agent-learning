# 不变量与对拍：用小输入找出大算法的边界

> [算法路线](00-guide.md) · 独立原创

**暴力解不是废稿：它既提供复杂度基线，也能当小输入的裁判。** 不变量则描述每轮开始或结束时必然成立的事实。

## 把正确性拆成三问

拿 `lowerBound([1,2,2,5], 2)` 举例：初始化时 `[0,n)` 待检查；每轮中点不够大，就排除它和更小的元素，否则将右边界收至中点；结束时候选区间长度为零，边界 `1` 就是答案。每轮必须严格缩小区间，否则证明只能说「如果结束，答案正确」。

对拍时用线性扫描当裁判，不要写另一个同样公式的二分。选小值域（如 `[-1,0,1]`）而不是随机大整数，重复、空数组和全等值才容易被覆盖。排序类算法还要验证输出多重集与不改输入的契约。

```ts
const index = values.findIndex(x => x >= target);
const expected = index < 0 ? values.length : index;
```

练习：用测试杀死 `hi = mid - 1` 这个变体，再加一个只检查是否循环结束的最小输入。

<details>
<summary>提示</summary>

`[1,2,2]` 找 `2` 应得 `1`；`[1]` 找 `2` 应得 `1`，这个用例可卡住把 `lo = mid + 1` 写成 `lo = mid` 的版本。对拍不能代替证明，但能很快区分边界写法。
