# 概率 DP：先到哪一边

> [算法路线](00-guide.md) · 独立原创

**「限时内先到右端」的概率，是下一步各去向的成功概率按发生率加权。** 用剩余步数分层就能直接填表；去掉时限后，状态可能互相依赖，需要解方程而不是换个遍历方向。

- [限时状态](#method)：每一步都读上一层。
- [解析验算](#worked-example)：同一走廊分别算两步内与无限时。
- [检验口径](#verify)：区分「在此之前」和「恰在此时」。

## 剩余步数把来回移动变成单向依赖 { #method }

前提：点编号 `0..L`，`L≥2`。在内部点，每一步独立地以概率 `p` 向右、以 `1-p` 向左，`0<p<1`；到达 `0` 或 `L` 就停止。目标是在最多 `T` 步内先到 `L`。若出发点就在边界，视为第 `0` 步到达。

| 状态 | `F[t,x]`：从 `x` 出发、最多 `t` 步内成功的概率 |
| --- | --- |
| 任意 `t`，`x=0` 或 `x=L` | 分别为 `0` 和 `1` |
| `t=0`，内部点 | `0` |
| `t≥1`，内部点 | `p·F[t-1,x+1] + (1-p)·F[t-1,x-1]` |

按第一步方向分事件，两个事件互斥且穷尽。走掉一步后，内部未来只取决于新位置和剩余步数。边界是吸收状态：不能从 `0` 继续走，也不能把已经到达的 `L` 当作超时。按 `t=1..T` 填内部点，读 `F[T,起点]`；用前后两层，时间 `O(L(T+1))`、空间 `O(L)`。

## 两个内点列出两个方程就能求最终成功率 { #worked-example }

令 `L=3`、`p=2/3`，逐层得到：

| 剩余步数 | `F[t,1]` | `F[t,2]` |
| --- | --- | --- |
| 0 | `0` | `0` |
| 1 | `0` | `2/3` |
| 2 | `4/9` | `2/3` |
| 3 | `4/9` | `22/27` |

从位置 `1` 两步内成功，只有「右、右」，概率 `4/9`。如果放开时限，记最终成功概率为 `H[x]`。边界仍是 `H[0]=0`、`H[3]=1`，两个内点由第一步得到 `H[1]=(2/3)H[2]`、`H[2]=2/3+(1/3)H[1]`，代入得 `H[1]=4/7`、`H[2]=6/7`。这与限时表不矛盾：前者还计入来回数次以后才到右端的路径。对一般 `L`，同样列式，可用差分 `H[x+1]-H[x]=((1-p)/p)(H[x]-H[x-1])`，先生成各差分的比例，再把它们归一化到和为 `1`；精确算术下需 `O(L)` 次运算，若只求一个位置可用常数个累加量。此处和限时版的复杂度都按每次算术为常数计。

## 累计概率不能跨时限直接相加 { #verify }

- **对称练习**：改用 `L=4`、`p=1/2`，从 `1` 出发最多两步成功率为 `0`（离右端还有三步）；不设时限则为 `1/4`，提示：相邻 `H` 的差相等。
- **反例**：上表从 `2` 出发，`F[1,2]=F[2,2]=2/3`。相加得到 `4/3`，因为第一步直接成功的同一批结果算了两遍。恰好在第 `t≥1` 步成功应取 `F[t,x]-F[t-1,x]`。
