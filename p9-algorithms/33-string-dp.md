# 字符串 DP：从两个前缀的末尾推转移

> [算法路线](00-guide.md) · 独立原创

**编辑距离、LCS 和子串问题都能用二维表，但状态和「不相等时怎么办」不能互抄。**

## 空前缀先决定一整行和一整列

Levenshtein 编辑距离的 `dp[i][j]` 是把 `a` 的前 `i` 项变成 `b` 的前 `j` 项最少操作。空串一侧成本等于另一侧长度。末码点相同用对角格；否则删除取上格、插入取左格、替换取对角格，各加 `1` 取最小。`ab→ba` 是 `2`，因为这里不支持把相邻交换当成一步。

最长公共子序列（LCS）末项相同取对角加一，否则取上格或左格较大。最长公共**子串**要求连续，`dp[i][j]` 若定义为在两处结尾的公共后缀长度，不相等就必须归零。编辑距离时间 `O(mn+m+n)`，实现的 DP 行空间 `O(n)`，字符拆分另用 `O(m+n)`，单位是 Unicode 码点。
