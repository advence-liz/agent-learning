# 树与图：DFS 汇总子树，BFS 按距离扩散

> [算法路线](00-guide.md) · 独立原创
>
> **一句话：**答案由子树汇总就用深度优先（DFS）；需要无权图的最少边数就用广度优先（BFS）。树没有回到祖先的边，普通图却可能有环或多个入口。


### 树的深度可以从子树向上汇总

把 `treeDepth(node)` 定义为「以这个节点为根的树，高度按节点数算」。空树返回 `0`；非空树返回 `1 + max(左树深度, 右树深度)`。最小调用自己就能回答，父节点只消费两个子结果。这里 DFS 先递归子树，再组合答案，是后序处理思路。

```ts
if (node === null) return 0;
return 1 + Math.max(treeDepth(node.left), treeDepth(node.right));
```

`O(n)` 时间，调用栈 `O(h)`；链状树的 `h` 可达 `n`，实际 JS 运行时可能栈溢出，超深输入应改显式栈。

### 无权图的距离在第一次入队时就确定

```d2
direction: down
a: A：距离 0
one: 第一层：B、D
c: C：距离 2
a -> one: A 直接到达 B 和 D
one -> c: 从 B 首次发现 C
```

图画的是发现顺序，不是完整邻接图。例子里 `C` 也能回到 `A`，而 `C → D` 更不能把已发现的 `D` 改成更远。实现把 `distance` 同时当已发现集合：发现时标记并入队；FIFO 保证距离为 `d` 的前沿会在 `d+1` 的节点出队前处理完。只有每条边成本相同、以边数为距离时，这个结论才成立。

邻接表（adjacency list）存每个点的出边；BFS 访问从起点可达的 `V` 个点和它们的 `E` 条出边，时间 `O(V+E)`、额外空间 `O(V)`（按哈希平均常数访问估算）。不可达点不在结果内。若要恢复路径，首次入队时再记一个 `parent`，最后从终点反向走回起点。见[完整实现](../code/algorithm-node/src/traversal.ts)。
