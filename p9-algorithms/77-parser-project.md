# 解析器实战：表达式优先级不是边扫描边求值就能解决

> [算法路线](00-guide.md) · 独立原创

**先把字符串变成 token，再按文法分层求值。** 运算符有优先级和结合性，需要可验证的语法契约。

定义 `expr = term ((+|-) term)*`，`term = factor ((*|/) factor)*`，`factor = number | -factor | (expr)`。每一层只消费自己的运算符；重复部分用循环做左结合，所以 `8/4/2` 等于 `(8/4)/2 = 1`，而 `-(2+3)*4` 等于 `-20`。词法层接受多位十进制整数和空白；错误 token、未闭合括号、尾随 token、除零显式报错。若使用 JavaScript `number` 做值语义，约定除法不是整数截断，并注明精度和有限值限制。

读取每个 token 一次，语法识别时间 `O(n)`，token 列表 `O(n)`，递归调用栈随括号和连续一元运算深度增长。极深嵌套应限制输入或改用运算符栈。完成基本版再增加指数，注意右结合与一元负号优先级要先定义。
