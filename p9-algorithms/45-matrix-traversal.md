# 二维遍历：转置、旋转与螺旋走的是不同下标

> [算法路线](00-guide.md) · 独立原创

**矩阵的形状是契约，不是所有二维算法都接受长方形。** 先写坐标映射，再问能否原地执行。

## 先写去向，再考虑碰撞

一个 `R×C` 矩阵顺时针旋转后是 `C×R`，原 `(r,c)` 到 `(c,R−1−r)`，可分配新矩阵一次遍历。正方形能先沿主对角线转置，再翻转每一行；转置只交换一半坐标，否则同一对会被换回去。两者都处理 `RC` 个单元；原地版本只适用于等宽等高。

顺时针螺旋不旋转任何数据：维护尚未读过的行列边界，读顶边后去掉顶行、读右边后去掉右列；读底边和左边前各检查空区间。高度或宽度为一时，再「无脑走四条边」会重复输出。遍历时间 `O(RC)`，不计输出额外空间 `O(1)`。
