# 二维矩阵：用四个角回答矩形范围和

> [算法路线](00-guide.md) · 独立原创

**二维前缀和把任意矩形求和变成四次查表。** 关键不是记公式，而是知道哪一块被减掉了两次。

## 左上角重复扣除，要加回来

令 `S[r][c]` 为前 `r` 行、前 `c` 列的和，矩形下右与上左都用半开边界。目标是 `S[bottom][right] - S[top][right] - S[bottom][left] + S[top][left]`。建表也用同样的容斥，再加当前单元格。零行和零列让首行首列不需要特判。

矩阵 `[[1,-2,3],[4,0,5]]` 查询所有行的列 `[1,3)`：答案 `6`。建表 `O(RC)`，每次查询 `O(1)`。输入必须矩形；若每次请求都带更改，静态表要重算，不能保留 `O(1)` 读取而忽略更新代价。旋转、转置或螺旋游走则改变访问顺序，不是同一个范围求和问题。

实现：[matrixSums 和 rectSum](../code/algorithm-node/src/ranges.ts)。
