# 数位与状压 DP：压缩的是重复状态，不是随意减维

> [算法路线](00-guide.md) · 独立原创

**数位 DP 压缩相同前缀约束；状压 DP 用位集合记录选过哪些项。** 两者都要保证状态足以决定未来。

## 用 `tight` 区分「跟上界齐平」和「已经更小」

统计 `[0,N]` 内二进制没有相邻 `1` 的数，状态是 `(pos, previous, tight)`。之前刚放 `1` 时禁止再放 `1`；仍贴着上界时本位只能不大于上界对应位，放更小一位后后缀自由。允许前导 0，使每个数字有唯一固定长度表示；这里不需要额外记录「是否开始」。若统计不含前导零的数字 `0` 出现次数，就需要显式区别。固定二进制下本题状态总量随位数线性，见[数位实现](../code/algorithm-node/src/dynamic.ts)。

状压路径问题常记 `dp[mask][last]`：集合相同但最后一项不同，下一条边的代价可能不同。遍历所有集合会指数增长，如旅行商 DP 时间 `O(n²·2^n)`；仅适合小 `n`。JS 位移会转成 32 位，不能把 `1 << 40` 当成大掩码。
