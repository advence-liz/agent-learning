# 有序流实战：把多个来源的最新记录合成一页

> [算法路线](00-guide.md) · 独立原创

**多个已按时间排序的来源只需归并当前头部；翻页边界则必须有稳定的全序键。**

设每个来源由新到旧排序，每条记录排序键是 `(timestamp,id)`，时间相同时按约定的全局唯一 ID 决定顺序。为所选来源放入各自第一条，最大堆弹出当前最新，再推进这一路，取满 `k` 条即可停。初始化堆若逐项推入要 `O(s log(s+1))`，其中 `s` 是非空来源数；用批量建堆则 `O(s)`，随后每页取 `k` 项要 `O(k log(s+1))`。未读取的后半段不计为本次归并必需工作。

如果下一页只传 `timestamp`，同一毫秒的未读记录可能被跳过。用上页最后 `(timestamp,id)` 作为排他游标；各来源能二分 seek 到游标后则不必重新从头拉。数据并发更新时，若要求稳定快照，还要约定读取版本或「截至何时」，单靠游标不保证加载两页的快照一致。

练习：造两路都在时间 `10` 有记录、页长 `1` 的输入，写不依赖来源读取顺序的验收。
