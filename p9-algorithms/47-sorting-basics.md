# 排序基础：用同一组记录看插入、选择、冒泡和堆排序

> [算法路线](00-guide.md) · 独立原创

**理解排序先看每轮保证了哪一段，再比较最坏时间、稳定性、额外空间。** 没有一种排序同时适合所有数据和接口。

| 方法 | 每轮结束后 | 稳定性与成本（数组实现） |
|---|---|---|
| 插入 | 已处理前缀有序；新项滑进空位 | 只挪严格大于项则稳定；逆序 `O(n²)`，已排序 `O(n)` |
| 选择 | 最小未定项被交换到边界 | 朴素交换不稳定；比较始终 `Θ(n²)` |
| 冒泡 | 一次从左到右推进最大未定项 | 仅换逆序邻项则稳定；加无交换早停后已排序 `O(n)` |
| 堆排序 | 把最大值换到末端，再缩小未排序堆 | 原地二叉堆实现不稳定；建堆 `O(n)`，整体最坏 `O(n log n)` |

以 `[(2,A),(2,B),(1,C)]` 为例，选择排序第一轮交换头尾，得到 `[(1,C),(2,B),(2,A)]`，两个 `2` 被反转。插入排序移动元素而不是交换远处的记录，对少量逆序特别便宜；`n` 个键、有 `I` 对逆序时，移动次数恰为 `I`。

练习：`[3,1,2]` 插入排序移动的旧项总共几次？如果比较器相等也移动，什么用例能验出问题？
