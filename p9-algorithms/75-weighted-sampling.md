# 带权随机：用前缀权重划出等概率的整数格

> [算法路线](00-guide.md) · 独立原创

**权重 `w` 不是输出 `w` 次，而是占据 `w` 个可抽到的格子。** 抽取和映射的端点必须精确对应。

权重 `[2,0,3]`，累计上界 `[2,2,5]`，从整数 `[0,5)` 均匀取 `r`，选择第一个累计上界严格大于 `r` 的下标。`0,1` 都落第一个，`2,3,4` 都落第三个，零权永不被选。建表 `O(n)`，每次二分 `O(log n)`，空间 `O(n)`。需要权重非负且总权重大于零，整数格模型要求随机源能均匀代表全部整数格；大权重别直接用 JS 浮点相乘做精确抽样。

权重频繁变化时，可以用树状数组维护累计权重并查首个累计过界的位置；累加权重不再单调（例如允许负权）时整个方法都无效。普通蓄水池对应未知总条数且等权的另一种场景。

练习：累计上界 `[0,4,4,5]`，随机格 `0`、`4` 分别选哪个下标？
