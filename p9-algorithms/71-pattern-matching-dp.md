# 模式匹配与分词：扫描位置相同，转移方向却不同

> [算法路线](00-guide.md) · 独立原创

**分词问能否从合法边界拆成词，简化正则问两段前缀是否完整匹配。** 都是布尔 DP，但失败分支不能混用。

分词设 `ok[0]=true`，`ok[i]` 表示文本前 `i` 项可拆成完整单词；存在 `ok[j]` 且 `[j,i)` 在词典就成功。朴素枚举 `O(n²)` 个边界对，切片成本要另计；可从合法 `j` 沿字典树扫描，最长词长 `L` 时耗时 `O(nL)` 级，假设查边平均常数。词典只含非空词。

只支持字面量、`.`、后缀 `*` 的**全串**匹配，状态为文本和模式两个前缀。末端不是 `*` 时须字符兼容且去掉两边末项仍匹配；末端是 `*` 时，选择不用它前一项（模式退两位），或兼容且再消费一个文本字符（模式长度不变）。空文本也可能匹配 `a*b*`。模式预先校验 `*` 有合法前项，时间 `O(nm)`、空间 `O(nm)`，含边界表。

练习：`ab` 匹配 `a*` 吗？`aaaaab` 能用 `aa,aaa` 分词吗？

<details>
<summary>提示</summary>

都不能；第一种不是子串匹配，第二种末尾 `b` 无词可接。额外用空串配 `a*b*` 验初始化。
