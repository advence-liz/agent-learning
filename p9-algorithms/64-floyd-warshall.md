# Floyd–Warshall 全源最短路

> [算法路线](00-guide.md) · 独立原创

当你需要一张任意两点间的最短路表，**让所有点依次获得「当中转」的资格，每次更新整张距离矩阵。** 中转点循环必须在最外层；有负环时再按每对起终点分别标记无下界。

- [定义中转层](#method)：直接边打底，接入中转点后比较两种走法。
- [手算距离矩阵](#worked-example)：逐轮追踪三点图的变化。
- [判定负环影响](#verify)：有负环不等于整张表无效。

## 每轮只新增一个允许中转的点 { #method }

前提：`V` 个点的有向带权图，允许负边和平行边。问每个有序点对最短距离，走法可重复点和边，允许零步。先考虑没有负环时的最短路。令 `D_k[i,j]` 表示只允许编号在前 `k` 个的点作为内部中转时，从 `i` 到 `j` 的最短距离。`D_0` 先全设 `+∞`，对角线设 `0`，每条直接边都与当前值取最小（包括自环和平行边）。

加入中转点 `k`：不经过它的最短路是旧 `D[i,j]`；经过它的最短路可拆为两段 `D[i,k]+D[k,j]`。没有负环时可删除不划算的环，所以不需要在最优走法里反复中转 `k`。也因为 `D[k,k]=0`，本轮 `k` 行与 `k` 列不会变小，可用同一张表更新：

```text
对 k 按既定点序：
    对每个 i：
        对每个 j：
            若 D[i,k] 和 D[k,j] 都有限：
                D[i,j] = min(D[i,j], D[i,k] + D[k,j])
```

时间 `O(V³+E)`（含读入 `E` 条边），矩阵额外空间 `O(V²)`。边存在但权重为 `0` 和根本没有边不是一回事。

## 三轮中转把直连代价扩成全源距离 { #worked-example }

点序 `A,B,C`；边为 `A→B(4)、A→C(9)、B→C(-2)、C→A(3)`，没有负环。下面每个括号是一整行，列按 `A,B,C` 排列：

| 允许的中转点 | 从 A | 从 B | 从 C |
| --- | --- | --- | --- |
| 无 | `(0,4,9)` | `(∞,0,-2)` | `(3,∞,0)` |
| A | `(0,4,9)` | `(∞,0,-2)` | `(3,7,0)` |
| A、B | `(0,4,2)` | `(∞,0,-2)` | `(3,7,0)` |
| A、B、C | `(0,4,2)` | `(1,0,-2)` | `(3,7,0)` |

例如首轮得到 `C→A→B=7`，次轮把 `A→C` 从直连的 `9` 改为 `4-2=2`。最后把 `C` 作为中转，`B→A` 从不可达变成 `-2+3=1`。

## 负对角线只会影响能经过该点的起终点对 { #verify }

有负环时仍可运行上述扫描：每个有限表项都来自某条真实走法，所有可达的有序点对都会成为有限；`D[k,k]<0` 说明已找到一条从 `k` 回到 `k` 的负权走法。无需要求每个受影响的点自己的对角线都为负：每个负简单环上，至少最后开放的点会被查出，因为环上其余点都已可中转。

先固定扫描得到的可达性，再对每个 `D[k,k]<0` 的点，把所有满足 `i` 可达 `k` 且 `k` 可达 `j` 的 `(i,j)` 标成 `-∞`。这恰好覆盖能绕负环的点对；其他点对不存在可利用的负环，原来的有限值仍正确，不可达仍为 `+∞`。标记过程至多再用 `O(V³)` 时间和 `O(V²)` 空间；不要边标 `-∞` 边用数值有限性来判断可达性。

- **循环顺序反例**：点序 `A,B,C,D`，只有 `A→D→C→B` 三条边、边权均为 `1`。若用 `i、j、k` 的循环顺序，处理 `(A,B)` 时 `A→C` 和 `D→B` 都尚未求出，可能把它留为 `∞`；正确答案是 `3`。
- **负环练习**：另建图 `X→Y(2)、Y→Y(-1)、P→Q(5)`。应有 `D[X,Y]=-∞`，但 `D[X,X]=0、D[Y,X]=+∞、D[P,Q]=5`。
