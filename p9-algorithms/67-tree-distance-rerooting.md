# 树上距离与重根 DP

> [算法路线](00-guide.md) · 独立原创

要求树上每个点到所有点的距离和，**先求一个根的答案，再沿每条边把答案推给邻点。** 换根跨过一条边时，一边所有距离都减一个边长，另一边所有距离都加一个边长，只需知道两边分别有多少点。

- [先做一遍后序](#method)：同时记录子树大小与向下距离和。
- [再做一遍前序](#worked-example)：一条边只用常数时间推出新答案。
- [逐点手算验收](#verify)：用不同初始根和小树全点搜索核对。

## 后序遍历先算出一个根的距离和 { #method }

前提：`n≥1` 个点、`n-1` 条边构成连通无向树，边长 `w≥0`；两点距离为唯一简单路径上的边长和。要求 `S[u]=Σ_x dist(u,x)`，把自己作为距离 `0` 的一项。不适用于有环、可绕路的图。

任选根 `r`，建出父子关系及遍历序。定义 `size[u]` 为含自身的子树点数，`down[u]` 为 `u` 到子树里所有点的距离和。先处理孩子，再处理父亲：

```text
size[u] = 1 + Σ size[v]
down[u] = Σ (down[v] + size[v] · w(u,v))
两式都对 u 的孩子 v 求和；叶子是 (1, 0)
```

从 `u` 到孩子 `v` 子树里的每个点都多走一条 `u—v`，所以要给 `down[v]` 加上整棵子树各走一次的边长。原根子树包含所有点，得到 `S[r]=down[r]`。

## 切开换根的那条边就知道有多少距离增减 { #worked-example }

固定最初的父子方向。对父 `u`、子 `v`，已知 `S[u]` 时，切开 `u—v` 得到两块：

| 点落在哪一边 | 点数 | 从 `u` 换到 `v` 时，每个点的距离变化 |
| --- | --- | --- |
| `v` 那侧 | `size[v]` | `-w(u,v)` |
| `u` 那侧 | `n-size[v]` | `+w(u,v)` |

因此 `S[v]=S[u]+(n-2·size[v])·w(u,v)`。第二趟按父先子后，把 `S` 从 `r` 逐级推下去；不重新计算 `size`，因为 `size[v]` 只用来数最初父子方向上切边后 `v` 那侧的点。两趟共 `O(n)` 时间；邻接表、状态数组和栈都只需 `O(n)` 空间。长链可用显式栈先记录顺序，再逆序跑后序。

## 只知道相邻节点的度数不够 { #verify }

五点树：`A—B` 长 `2`、`A—C` 长 `1`、`B—D` 长 `3`、`B—E` 长 `1`。以 `A` 为根，`B` 的子树有三点，`down[B]=3+1=4`。于是 `down[A]=(4+3·2)+(0+1·1)=11`：

| 点 | 初始 `size` | `down` | 到全树距离和 `S` |
| --- | --- | --- | --- |
| A | 5 | 11 | 11 |
| B | 3 | 4 | `11+(5-6)·2=9` |
| C | 1 | 0 | `11+(5-2)·1=14` |
| D | 1 | 0 | `9+(5-2)·3=18` |
| E | 1 | 0 | `9+(5-2)·1=12` |

- **反例**：单位边长六点链 `A—B—C—D—E—F`，`B、C、D` 度数都是 `2`。从 `B` 换到 `C`，四个点变近、两个点变远，距离和减 `2`；从 `C` 换到 `D`，两边各有三个点，距离和不变。只看两端度数会给出同样的变化，必有一处错。
- **边界练习**：单点输出 `0`；四点单位边长星形，中心为 `3`，每片叶子为 `5`。把一条边权改成 `0`，该边两端的距离和必须相等。

<summary>核验提示</summary>

从每个点各走一遍树，沿边累计距离并求和，`O(n²)` 的办法可作小数据基准；再改选初始根重算，按节点编号的输出不得变化。
